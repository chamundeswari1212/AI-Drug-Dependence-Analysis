AI-Drug-Rehab-Assessment

💊 Innovative AI Solutions for Drug Dependence

This project uses advanced AI models like XGBoost, Random Forest, and Neural Networks to assess and support rehabilitation for drug dependence.

🚀 Features
	•	Predict rehabilitation success
	•	Analyze patient data
	•	Support decision-making in treatment plans

🧑‍💻 Models Used
	•	XGBoost
	•	Random Forest
	•	Neural Networks (TensorFlow)

⚙️ Requirements
	•	Python 3.12
	•	streamlit
	•	xgboost
	•	tensorflow
	•	scikit-learn
	•	pandas
	•	streamlit-lottie

Install using:
pip install -r requirements.txt

💡 How to Run
streamlit run app1.py
